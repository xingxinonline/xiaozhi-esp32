# JoyInside 语音助手 - 用户使用指南

> 基于蓝豆包 ESP32-S3 开发板的智能语音助手

## 🚀 快速开始

### 第一次使用

1. **上电开机** - 插入 Type-C 电源线，设备自动启动
2. **配置 WiFi** - 首次使用需要配置 WiFi 网络（详见下方配网流程）
3. **自动注册** - 首次联网时设备会自动注册，获取唯一标识
4. **等待就绪** - 注册并连接到对话服务后会播放成功提示音
5. **开始对话** - 说 **"你好东东"** 或 **"你好京东"** 唤醒设备，唤醒成功有提示音

> 💡 **提示**：设备首次注册后，标识信息会永久保存，重启后无需重新注册

### 📶 蓝牙配网流程

1. **进入配网模式**
   - 长按设备黑色按键，设备会播放「进入配网模式」提示音
   - LED 指示灯开始闪烁

2. **打开小程序**
   - 微信搜索小程序 **"Bluepebo"** 并进入
   - 完成登录

3. **添加设备**
   - 点击页面右下角 **"+"** 号按钮
   - 小程序自动搜索附近设备
   - 在列表中找到 **"LanDouBao-XXXX"** (XXXX 为设备编号)
   - 点击设备进入配网界面

4. **配置 WiFi**
   - 在 WiFi 列表中选择目标网络名称（需 2.4GHz）
   - 在弹窗中输入正确的 WiFi 密码
   - 点击 **"发送"** 按钮

5. **等待完成**
   - 等待配网成功提示
   - 设备自动重启
   - 网络正常时，连接到对话服务后会播放成功提示音 ✅

> 💡 **提示**：配网完成后，设备会记住 WiFi 信息，下次上电自动连接

### LED 指示灯说明

| LED 状态 | 颜色 | 含义                |
| -------- | ---- | ------------------- |
| 快闪     | 🔵 蓝 | 启动中 / 连接服务器 |
| 慢闪     | 🔵 蓝 | 配网模式            |
| 呼吸灯   | 🔵 蓝 | ✅ 待机（可以唤醒）  |
| 常亮     | 🔵 蓝 | ✅ 对话中（请说话）  |
| 常亮     | 🔴 红 | AI 正在说话         |
| 快闪     | 🔴 红 | ❌ 网络异常          |
| 快闪     | 🟣 紫 | 升级中              |
| 慢闪     | 🟣 紫 | 激活中              |

> 💡 **用户决策指南**：
> - 🔵 蓝色呼吸 → 网络正常，可以唤醒
> - 🔵 蓝色常亮 → 已唤醒，请说话
> - 🔴 红色快闪 → 网络问题，请等待恢复
> - 🔵 蓝色慢闪 → 配网模式，请用小程序配网

## 🗣️ 语音交互

### 基本对话流程

```
1️⃣ 唤醒          2️⃣ 聆听          3️⃣ 思考          4️⃣ 回答
  说唤醒词   →    说出问题    →   等待处理   →   听取回答
"你好东东"      "今天天气"       处理中...      播放回答
   (叮~)
```

> 🔔 唤醒成功后会听到"叮"的提示音，表示设备已进入聆听状态

### 唤醒词

| 唤醒词       | 说明       |
| ------------ | ---------- |
| **你好东东** | 默认唤醒词 |
| **你好京东** | 备选唤醒词 |

> 💡 **提示**：在安静环境下，正常说话音量即可唤醒。两个唤醒词效果相同，选择顺口的即可

### 对话技巧

#### ✨ 连续对话（推荐）

你可以把唤醒词和问题**连着说**，不需要等待：

```
❌ 传统方式：
   "你好东东" → (等待) → "今天天气怎么样"

✅ 连续方式：
   "你好东东今天天气怎么样"  ← 一口气说完
```

这样更自然，响应也更快！

#### ⚡ 快速打断

AI 回答时，你可以**随时说话打断**：

```
AI: "今天北京天气晴朗，温度..."
你: "那明天呢？"  ← 直接说话打断
AI: "明天北京多云..."  ← 回答新问题
```

#### 🔄 多轮对话

对话模式为**实时模式**，可以随时说话打断设备播放。AI 回答完毕后的 **2 分钟内**，可以继续对话：

```
你: "你好东东，北京天气"
AI: "北京今天晴，25度..."
    
(等待 AI 说完)

你: "你好京东，那上海呢？"  ← 继续问
AI: "上海今天多云，23度..."
```

> ⏱️ **注意**：两分钟内没有语音输入则自动结束对话，需要再次唤醒使用

## 🎛️ 按钮操作

### 单按钮控制（黑色按键 / BOOT 键）

| 操作     | 功能                        |
| -------- | --------------------------- |
| **短按** | 音量 +10%（满后循环回 10%） |
| **双击** | 音量 -10%（最低 0%）        |
| **长按** | 进入配网模式                |

### 音量循环

```
短按: 10% → 20% → 30% → ... → 100% → 10% → ...
双击: 100% → 90% → 80% → ... → 10% → 0%
```

## 📊 状态指示

### 设备状态

| 状态     | LED 指示   | 提示音 | 说明               |
| -------- | ---------- | ------ | ------------------ |
| 待机中   | 🔵 蓝色呼吸 | 无     | 网络正常，等待唤醒 |
| 对话中   | 🔵 蓝色常亮 | "叮"   | 已唤醒，请说话     |
| AI回答   | 🔴 红色常亮 | 无     | AI 正在回答        |
| 网络异常 | 🔴 红色快闪 | 警告音 | 正在重连，请等待   |

### 网络状态提示音

| 提示音       | 含义     | 说明                            |
| ------------ | -------- | ------------------------------- |
| 短促警告音 ⚠️ | 网络断开 | WiFi 或服务器连接断开，正在重连 |
| 成功提示音 ✅ | 网络恢复 | 已重新连接到服务器，可正常使用  |

> 💡 **提示**：听到警告音后请耐心等待，设备会自动尝试重连。听到成功音表示网络已恢复正常。

### WiFi 状态

| 信号强度  | RSSI 范围 | 说明           |
| --------- | --------- | -------------- |
| ████ 优秀 | > -50 dBm | 信号很强       |
| ███░ 良好 | -50 ~ -60 | 信号正常       |
| ██░░ 一般 | -60 ~ -70 | 可能有延迟     |
| █░░░ 较弱 | < -70 dBm | 建议靠近路由器 |

## ⚠️ 注意事项

### 使用环境

| ✅ 推荐    | ❌ 避免     |
| --------- | ---------- |
| 安静室内  | 嘈杂环境   |
| 正常说话  | 距离太远   |
| 稳定 WiFi | 信号弱区域 |
| 清晰发音  | 口齿不清   |

### 电源要求

- 使用 **5V/1A** 或更高规格的电源
- 推荐使用质量好的 Type-C 数据线
- 不稳定的电源可能导致重启

### 网络要求

- 需要 **2.4GHz WiFi**（不支持 5GHz）
- 确保 WiFi 能访问互联网
- 延迟高的网络会影响体验

## 🔧 故障排除

### 问题：说唤醒词没反应

1. **检查音量** - 确保设备没有静音
2. **发音清晰** - 标准普通话发音
3. **距离适中** - 建议 0.5~2 米距离
4. **环境安静** - 避免背景噪音干扰

### 问题：回答断断续续

1. **检查 WiFi** - 查看信号强度
2. **靠近路由器** - 改善信号质量
3. **重启设备** - 长按电源键重启

### 问题：设备无响应

1. **检查电源** - 确保供电正常
2. **重新插拔** - 断电后重新上电
3. **等待启动** - 开机需要几秒钟

### 问题：WiFi 连接失败

1. **检查密码** - 确保 WiFi 密码正确
2. **2.4GHz** - 必须使用 2.4GHz 网络
3. **信号强度** - 确保 WiFi 信号覆盖

### 问题：听到警告音后没反应

1. **耐心等待** - 设备正在自动重连，通常 5-10 秒内恢复
2. **检查路由器** - 确保 WiFi 路由器正常工作
3. **靠近路由器** - 信号弱可能导致频繁断连
4. **听到成功音** - 表示已恢复，可以正常使用

- 🗣️ **清晰发音**，语速适中

- 📝 问题**具体明确**
