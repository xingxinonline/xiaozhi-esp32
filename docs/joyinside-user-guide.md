# JoyInside 语音助手 - 用户使用指南

> 让你的 ESP32-S3 开发板变身智能语音助手

## 🚀 快速开始

### 第一次使用

1. **上电开机** - 插入 Type-C 电源线，设备自动启动
2. **配置 WiFi** - 首次使用需要配置 WiFi 网络
3. **等待就绪** - 屏幕显示 WiFi 信号图标表示已连接
4. **开始对话** - 说 **"你好东东"** 唤醒设备

### 屏幕显示说明

```
┌─────────────────────────┐
│ 📶 WiFi信号   🔋 电量    │  ← 状态栏
├─────────────────────────┤
│                         │
│      😊 表情/状态       │  ← 主显示区
│                         │
├─────────────────────────┤
│    当前状态/对话内容     │  ← 信息栏
└─────────────────────────┘
```

| 图标 | 含义             |
| ---- | ---------------- |
| 📶    | WiFi 信号强度    |
| 🔋    | 电池电量（如有） |
| 😊    | 设备表情状态     |

## 🗣️ 语音交互

### 基本对话流程

```
1️⃣ 唤醒          2️⃣ 聆听          3️⃣ 思考          4️⃣ 回答
  说唤醒词   →    说出问题    →   等待处理   →   听取回答
"你好东东"      "今天天气"       处理中...      播放回答
   (叮~)
```

> 🔔 唤醒成功后会听到"叮"的提示音，表示设备已进入聆听状态

### 唤醒词

| 唤醒词       | 说明       |
| ------------ | ---------- |
| **你好东东** | 默认唤醒词 |

> 💡 **提示**：在安静环境下，正常说话音量即可唤醒

### 对话技巧

#### ✨ 连续对话（推荐）

你可以把唤醒词和问题**连着说**，不需要等待：

```
❌ 传统方式：
   "你好东东" → (等待) → "今天天气怎么样"

✅ 连续方式：
   "你好东东今天天气怎么样"  ← 一口气说完
```

这样更自然，响应也更快！

#### ⚡ 快速打断

AI 回答时，你可以**随时说话打断**：

```
AI: "今天北京天气晴朗，温度..."
你: "那明天呢？"  ← 直接说话打断
AI: "明天北京多云..."  ← 回答新问题
```

#### 🔄 多轮对话

在 AI 回答完毕后的 **2 分钟内**，可以直接继续对话：

```
你: "你好东东，北京天气"
AI: "北京今天晴，25度..."
    
(等待 AI 说完)

你: "你好东东，那上海呢？"  ← 继续问
AI: "上海今天多云，23度..."
```

## 🎛️ 按钮操作

### 单按钮控制（BOOT 键）

| 操作     | 功能                        |
| -------- | --------------------------- |
| **单击** | 音量 +10%（满后循环回 10%） |
| **双击** | 音量 -10%（最低 0%）        |
| **长按** | 开始/停止对话               |

### 音量循环

```
单击: 10% → 20% → 30% → ... → 100% → 10% → ...
双击: 100% → 90% → 80% → ... → 10% → 0%
```

## 📊 状态指示

### 设备状态

| 状态   | 屏幕显示     | 说明             |
| ------ | ------------ | ---------------- |
| 待机中 | 待机表情     | 等待唤醒词       |

### WiFi 状态

| 信号强度  | RSSI 范围 | 说明           |
| --------- | --------- | -------------- |
| ████ 优秀 | > -50 dBm | 信号很强       |
| ███░ 良好 | -50 ~ -60 | 信号正常       |
| ██░░ 一般 | -60 ~ -70 | 可能有延迟     |
| █░░░ 较弱 | < -70 dBm | 建议靠近路由器 |

## ⚠️ 注意事项

### 使用环境

| ✅ 推荐    | ❌ 避免     |
| --------- | ---------- |
| 安静室内  | 嘈杂环境   |
| 正常说话  | 距离太远   |
| 稳定 WiFi | 信号弱区域 |
| 清晰发音  | 口齿不清   |

### 电源要求

- 使用 **5V/1A** 或更高规格的电源
- 推荐使用质量好的 Type-C 数据线
- 不稳定的电源可能导致重启

### 网络要求

- 需要 **2.4GHz WiFi**（不支持 5GHz）
- 确保 WiFi 能访问互联网
- 延迟高的网络会影响体验

## 🔧 故障排除

### 问题：说唤醒词没反应

1. **检查音量** - 确保设备没有静音
2. **发音清晰** - 标准普通话发音
3. **距离适中** - 建议 0.5~2 米距离
4. **环境安静** - 避免背景噪音干扰

### 问题：回答断断续续

1. **检查 WiFi** - 查看信号强度
2. **靠近路由器** - 改善信号质量
3. **重启设备** - 长按电源键重启

### 问题：设备无响应

1. **检查电源** - 确保供电正常
2. **重新插拔** - 断电后重新上电
3. **等待启动** - 开机需要几秒钟

### 问题：WiFi 连接失败

1. **检查密码** - 确保 WiFi 密码正确
2. **2.4GHz** - 必须使用 2.4GHz 网络
3. **信号强度** - 确保 WiFi 信号覆盖

## 💡 小贴士

### 提高识别率

- 🎯 说话时**面向设备**
- 🔊 保持**适中音量**，不需要大喊
- 🗣️ **清晰发音**，语速适中
- 🤫 尽量在**安静环境**使用

### 获得更好回答

- 📝 问题**具体明确**
- 🔄 可以**追问补充**细节
- ⏸️ 给 AI **思考时间**
- 🔁 没听清可以**重新问**

### 省电技巧

- 🔋 不使用时可以**断电**
- 📶 保持**良好 WiFi**（弱信号更耗电）
- 🔊 适当**降低音量**
