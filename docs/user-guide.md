# 智伴AI阅读助手使用说明

> 本说明适用于智伴AI阅读助手。
>
> 本设备仅支持微信小程序蓝牙配网，不支持热点配网、浏览器配网或 4G 配网。

## 快速开始

1. 接通电源并按设备外壳说明开机。
2. 打开手机蓝牙和微信，使用配套微信小程序完成配网。
3. 如设备提示激活，请按小程序或页面提示完成绑定。
4. 说出唤醒词，或单击主按键，开始与 AI 对话。

## 设备特点

- 支持语音对话、阅读陪伴和日常问答
- 支持唤醒词唤醒和单按键交互
- 通过微信小程序蓝牙配网接入 Wi-Fi
- 带屏幕，可显示状态、消息和电量信息
- 内置电池，支持日常移动使用

## 首次使用前的准备

建议先准备好以下内容：

- 稳定电源，或确保设备电量充足
- 可正常使用的 2.4GHz Wi-Fi 网络和密码
- 一部已安装微信的手机
- 已开启手机蓝牙

> 提示：本设备通常只支持连接 2.4GHz Wi-Fi，不支持直接连接 5GHz Wi-Fi。

## 首次开机

首次开机时，设备通常会依次完成以下步骤：

1. 初始化硬件
2. 进入配网流程
3. 联网后完成服务初始化
4. 连接服务器
5. 如有需要，进入激活流程
6. 进入待命状态

首次启动时间通常会比平时稍长。请保持供电稳定，不要频繁断电重启。

## 联网说明

智伴AI阅读助手只有一种联网方式：微信小程序蓝牙配网。

### 微信小程序蓝牙配网

操作步骤：

1. 打开手机蓝牙。
2. 打开微信，进入配套小程序。
3. 在小程序中搜索附近设备，并选择智伴AI阅读助手。
4. 在小程序中选择要连接的 Wi-Fi，并输入密码。
5. 提交后等待设备完成联网。
6. 设备显示连接成功或进入待命状态后，即可开始使用。

使用要点：

- 配网时请让手机靠近设备。
- 请确保手机连接的是 2.4GHz Wi-Fi。
- Android 手机如搜索不到设备，通常还需要打开定位权限。
- 本设备不提供热点页面，也不需要在浏览器中输入地址。

### 如何重新进入配网模式

在以下情况下，设备通常会进入或重新进入配网模式：

- 首次开机且还没有保存过 Wi-Fi 信息
- 重启设备后，在启动阶段单击主按键

如果设备已经正常进入待命状态，再单击主按键通常是用于对话控制，而不是重新配网。

## 激活与绑定

联网成功后，设备可能会自动进入激活流程。

如果屏幕显示激活码、提示链接或“激活设备”等信息，请按页面提示完成操作。常见流程如下：

1. 打开小程序或提示页面
2. 登录或注册账号
3. 输入设备显示的激活码，或按引导完成绑定
4. 等待设备回到待命状态

如果你的设备接入官方服务，绑定流程通常会关联到 xiaozhi.me 控制台；如果接入的是定制服务，请以设备提供方说明为准。

## 日常使用

### 开始对话

常见方式有两种：

- 说出唤醒词
- 单击主按键

设备进入对话后，常见状态包括：

| 状态     | 含义                                 |
| -------- | ------------------------------------ |
| 待命     | 设备已开机并在线，等待你的指令       |
| 聆听中   | 设备正在收听你的语音                 |
| 说话中   | AI 正在播报回复                      |
| 配网模式 | 设备等待你通过微信小程序完成联网配置 |

### 打断和停止

当设备正在播报时，通常可以通过以下方式打断：

- 再次说出唤醒词
- 单击主按键

### 按键操作

智伴AI阅读助手为单主按键设备，常见操作如下：

- 启动阶段单击：进入配网模式
- 正常使用时单击：唤醒、开始对话或打断当前播报
- 空闲状态双击：切换语音打断模式

本设备说明中不包含热点配网、浏览器配网、4G 切换等操作。

### 屏幕、指示灯与提示音

设备会通过屏幕、提示音和状态灯反馈当前状态。常见情况包括：

- 待命时显示主界面或状态信息
- 配网时显示配网相关提示
- 对话时显示状态、消息或内容
- 低电量时给出充电提醒

如果设备已经联网但屏幕没有正常显示，请先确认电量、亮度和供电是否正常。

## 控制台与个性化设置

如果你的设备接入官方服务，可以登录 xiaozhi.me 控制台查看设备状态并进行配置。

常见可用设置包括：

- 设备绑定和管理
- 角色、人设或对话风格
- 部分语音、语言和设备设置

不同账号、服务和固件版本看到的选项可能不同，请以实际页面为准。

## 维护与版本更新

智伴AI阅读助手不支持远程 OTA 升级。

如果后续需要更新版本，请联系设备提供方、售后人员，或按专用刷机流程处理，不要自行按照通用 OTA 方式操作。

日常使用中请注意：

- 保持供电稳定
- 不要频繁强制重启
- 不要在电量过低时长时间连续使用
- 如需检修或重装系统，请优先联系售后

## 常见问题

### 小程序搜不到设备

请依次检查：

1. 手机蓝牙是否已经开启
2. 微信小程序是否已获得蓝牙权限
3. Android 手机是否已开启定位权限
4. 手机与设备距离是否过远
5. 设备是否已经进入配网模式

### 配网失败

请依次检查：

1. 路由器是否开启了 2.4GHz Wi-Fi
2. Wi-Fi 密码是否输入正确
3. 路由器信号是否稳定
4. 手机当前是否连接在可用的 2.4GHz Wi-Fi 上

如果仍然失败，请重启设备，并在启动阶段单击主按键后重新配网。

### 已联网但不能正常对话

可能原因包括：

- 设备仍在激活或初始化中
- 当前服务暂时不可用
- 网络质量较差

建议等待 1 到 2 分钟后再试一次，必要时重启设备。

### 唤醒词无响应

请检查：

1. 当前环境是否过于嘈杂
2. 麦克风孔是否被遮挡
3. 你与设备的距离是否过远
4. 当前是否处于播报、初始化或异常状态

如果唤醒词暂时没有响应，也可以直接单击主按键开始对话。

### 电量低或频繁关机

当设备提示“电量低，请充电”或“电量不足”时，请尽快充电。

如果设备插电后仍频繁重启，请更换稳定的充电头或线材。

## 使用建议

- 将设备放在通风、干燥、远离水汽的位置
- 不要遮挡麦克风、扬声器和散热区域
- 在安静环境中使用，识别效果更好
- 长时间不用时，请按设备说明关机或断开外部电源

## 隐私提示

设备在联网对话时，语音音频、文本请求和设备状态会发送到当前连接的服务端进行处理。

如果你使用的是官方服务，请查看官方服务的相关说明；如果你使用的是第三方或自建服务，请确认其隐私和数据管理策略后再投入正式使用。
