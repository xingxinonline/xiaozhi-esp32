# 智伴AI阅读助手用户说明书

> 欢迎使用智伴AI阅读助手。
>
> 本产品采用单按键设计，首次使用请通过微信小程序完成蓝牙配网。

## 一、先看这四点

1. 使用时，主要通过提示音、状态灯和微信小程序了解产品状态。
2. 首次联网成功后，微信小程序会自动完成绑定。
3. 首次使用请通过微信小程序完成蓝牙配网。
4. 如需升级，请联系设备提供方或售后处理。

## 二、首次使用前，请先准备

- 一部已安装微信的手机
- 已开启蓝牙
- 可正常使用的 2.4GHz Wi-Fi 和密码
- 稳定电源，或确认阅读助手电量充足

> 温馨提示：请提前准备可正常使用的 2.4GHz Wi-Fi。

## 三、产品会怎样提醒你

日常使用中，你可以通过提示音和状态灯，大致判断阅读助手当前在做什么。

| 你听到 / 看到的现象 | 这通常表示什么 | 你现在该怎么做 |
| --- | --- | --- |
| 开机后状态灯快速闪烁 | 阅读助手正在启动 | 稍等片刻，不要频繁按键 |
| 听到配网提示音，状态灯慢闪 | 阅读助手已进入配网模式 | 打开微信小程序，开始蓝牙配网 |
| 状态灯微亮常亮 | 阅读助手处于待机状态 | 可以说唤醒词，或单击主按键开始对话 |
| 听到一声短提示音，状态灯呈呼吸变化 | 阅读助手开始听你说话 | 直接开始说话即可 |
| 状态灯较亮常亮 | 阅读助手正在播报内容 | 如需打断，可按当前模式或单击按键操作 |
| 听到成功提示音 | 阅读助手已联网成功，或网络恢复正常 | 可以继续正常使用 |
| 听到异常提示音 | 常见于网络断开或连接异常 | 检查 Wi-Fi、供电和网络环境 |

### 记住这三种提示就够了

- 配网提示音：表示阅读助手已经进入配网模式。
- 短提示音：表示阅读助手已经开始听你说话。
- 成功 / 异常提示音：表示联网成功，或网络出现异常。

如果一时分不清当前状态，以微信小程序提示为准，再结合状态灯判断即可。

## 四、第一次联网这样做

请按下面顺序操作：

1. 给阅读助手接通电源并开机。
2. 如果听到配网提示音、看到状态灯慢闪，说明已经进入配网模式。
3. 如果没有进入配网模式，请重启阅读助手，并在刚开机时单击主按键一次。
4. 打开微信，进入配套小程序。
5. 按小程序提示搜索附近的阅读助手。
6. 选择智伴AI阅读助手。
7. 在小程序中选择要连接的 2.4GHz Wi-Fi，并输入密码。
8. 等待小程序提示配网成功。
9. 配网成功后，小程序会自动完成当前用户与阅读助手绑定。
10. 小程序提示绑定完成后，即可开始使用。

### 小提示

- 整个过程以小程序提示为准。
- 首次开机和首次配网时，等待时间可能会比平时稍长，这属于正常现象。

## 五、日常使用

### 1. 开始对话

你可以通过下面两种方式开始对话：

- 说出唤醒词
- 单击主按键

当阅读助手开始听你说话时，通常会发出一声短提示音，同时状态灯会进入呼吸变化状态。这时直接说话即可。

### 2. 播报时如何打断

当阅读助手正在播报时，可以按当前对话方式进行打断：

- 连续对话模式：直接开口说话，就可以打断当前播报。
- 单轮问答模式：再次说出唤醒词，可以打断当前播报并开始下一轮对话。
- 如果你不方便用语音，任何时候都可以单击主按键打断当前播报。

### 3. 两种使用方式

阅读助手支持两种对话方式：

- 连续对话模式：更适合连续交流。播报过程中，直接开口就可以继续聊。
- 单轮问答模式：更适合一问一答。播报过程中，需要再次说出唤醒词，才会进入下一轮对话。

如果你对模式没有特别要求，保持当前默认设置即可。

### 4. 如何切换对话方式

在空闲状态下，双击主按键，可以在两种对话方式之间切换。

当前选择会自动保存，下次开机后仍然生效。

> 说明：最容易确认当前模式的方法，是在阅读助手播报时试一次打断方式：
>
> - 直接开口就能打断，说明当前是连续对话模式。
> - 需要再次说唤醒词才能打断，说明当前是单轮问答模式。

## 六、按键说明

阅读助手只有一个主按键，常用操作如下：

- 刚开机时单击：进入配网模式
- 平时单击：开始对话
- 对话或播报过程中单击：打断或结束当前这轮对话
- 空闲时双击：切换对话方式

> 提醒：如需重新配网，请重启阅读助手后在刚开机时单击主按键。

## 七、这些情况需要重新配网

遇到下面这些情况时，可以重新配网：

- 更换了家里的 Wi-Fi
- 小程序一直提示阅读助手未联网
- 阅读助手长时间无法正常连接使用

重新配网方法：

1. 重启阅读助手。
2. 在刚开机时单击主按键。
3. 确认阅读助手发出配网提示音、状态灯开始慢闪。
4. 重新打开微信小程序，按提示完成配网。

## 八、充电与日常使用建议

- 请尽量使用稳定的电源、充电头和线材。
- 如果插电后仍然频繁重启、反复断网或无法正常使用，请优先检查供电是否稳定。
- 使用时请不要遮挡麦克风和扬声器位置。
- 建议在相对安静的环境中使用，识别效果更好。
- 长时间不用时，请按产品说明关机或断开外部电源。

## 九、常见问题

### 1. 小程序搜不到阅读助手怎么办

请依次检查：

1. 手机蓝牙是否已开启。
2. 微信小程序是否已获得蓝牙权限。
3. Android 手机是否已开启定位权限。
4. 手机和阅读助手距离是否过远。
5. 阅读助手是否已经进入配网模式，也就是是否听到了配网提示音、看到了状态灯慢闪。

### 2. 配网失败怎么办

请依次检查：

1. 路由器是否开启了 2.4GHz Wi-Fi。
2. Wi-Fi 密码是否输入正确。
3. 路由器信号是否稳定。
4. 手机当前是否连接在可用的 2.4GHz Wi-Fi 上。

如果仍然失败，请重启阅读助手，并在刚开机时单击主按键后重新配网。

### 3. 配网成功后，为什么还不能马上使用

配网成功后，小程序还会继续完成当前用户和阅读助手的绑定。

请以小程序提示为准，等绑定完成后再开始使用。

### 4. 我怎么知道阅读助手已经在听我说话了

通常会有两个明显信号：

- 你会听到一声短提示音。
- 你会看到状态灯进入呼吸变化状态。

这时就可以直接开始说话。

### 5. 播报时能不能直接再说唤醒词来打断

要看你当前使用的是哪一种对话方式：

- 如果是连续对话模式：直接开口说话即可打断。
- 如果是单轮问答模式：再次说出唤醒词，可以打断当前播报。

如果你不方便用语音，仍然可以直接单击主按键打断。

### 6. 唤醒词没反应怎么办

请依次检查：

1. 当前环境是否过于嘈杂。
2. 麦克风孔是否被遮挡。
3. 你与阅读助手的距离是否过远。
4. 阅读助手是否刚开机、正在播报或网络异常。

如果唤醒词暂时没有响应，也可以直接单击主按键开始对话。

### 7. 双击后为什么感觉没变化

双击主按键后，阅读助手会切换对话方式。

你可以用下面的方法判断：

- 如果阅读助手播报时，你直接开口就能打断，说明当前是连续对话模式。
- 如果阅读助手播报时，需要再次说唤醒词才能打断，说明当前是单轮问答模式。

## 十、维护与售后

- 如需升级、检修、重装或恢复，请优先联系设备提供方或售后人员。
- 不建议自行按照通用刷机教程操作，以免影响正常使用。

## 十一、隐私提示

阅读助手在联网对话时，需要将语音和相关请求发送到对应服务端处理。

如你使用的是官方服务，请以官方说明为准；如你使用的是定制服务，请以对应服务提供方说明为准。
