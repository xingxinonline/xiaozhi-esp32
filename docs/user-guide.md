# 智伴AI阅读助手用户说明书

> 本说明适用于智伴AI阅读助手。
>
> 本设备为单按键设计，仅支持微信小程序蓝牙配网。

## 一、先知道这四点

1. 使用时请重点看提示音、状态灯和微信小程序提示。
2. 本设备没有单独激活步骤，配网成功后会由微信小程序自动完成绑定。
3. 本设备只支持微信小程序蓝牙配网，不需要连热点，也不需要打开浏览器输入地址。
4. 本设备不支持远程在线升级，后续如需升级，请联系设备提供方或售后处理。

## 二、第一次使用前，请先准备

- 一部已安装微信的手机
- 已开启手机蓝牙
- 可正常使用的 2.4GHz Wi-Fi 和密码
- 稳定电源，或确保设备电量充足

> 提示：本设备通常只支持 2.4GHz Wi-Fi，不支持直接连接 5GHz Wi-Fi。

## 三、设备会怎样提示你

你可以按下面的方式理解它当前在做什么。

| 你听到 / 看到的现象 | 这通常表示什么 | 你现在该怎么做 |
| --- | --- | --- |
| 开机后状态灯快速闪烁 | 设备正在启动 | 稍等片刻，不要频繁按键 |
| 听到配网提示音，状态灯慢闪 | 设备已进入配网模式 | 打开微信小程序，开始蓝牙配网 |
| 状态灯微亮常亮 | 设备处于待机状态 | 可以说唤醒词，或单击主按键开始对话 |
| 听到一声短提示音，状态灯呈呼吸变化 | 设备开始听你说话 | 直接开始说话即可 |
| 状态灯较亮常亮 | 设备正在播报内容 | 如需打断，可按当前模式或单击按键操作 |
| 听到成功提示音 | 设备已联网成功，或网络恢复正常 | 可以继续正常使用 |
| 听到异常提示音 | 常见于网络断开或连接异常 | 检查 Wi-Fi、供电和网络环境 |

### 关于提示音，重点记住三种就够了

- 配网提示音：表示设备进入了配网模式。
- 短提示音：表示设备已经开始听你说话。
- 成功 / 异常提示音：表示联网成功，或网络出现异常。

如果你一时分不清当前状态，最稳妥的判断方法是同时看状态灯和微信小程序提示。

## 四、首次配网与绑定

请按下面顺序操作：

1. 给设备接通电源并开机。
2. 如果设备发出配网提示音、状态灯慢闪，说明已经进入配网模式。
3. 如果没有进入配网模式，请重启设备，并在启动过程中单击主按键一次。
4. 打开微信，进入配套小程序。
5. 按小程序提示搜索附近设备。
6. 选择智伴AI阅读助手。
7. 在小程序中选择要连接的 2.4GHz Wi-Fi，并输入密码。
8. 等待小程序提示配网成功。
9. 配网成功后，小程序会自动完成当前用户与设备绑定。
10. 小程序提示绑定完成后，即可开始使用。

### 说明

- 本设备不需要额外激活。
- 首次开机和首次配网时，等待时间可能会比平时稍长，这属于正常现象。

## 五、日常怎么用

### 1. 开始对话

你可以通过以下两种方式开始对话：

- 说出唤醒词
- 单击主按键

开始进入收音时，设备通常会发出一声短提示音，同时状态灯会进入呼吸变化状态。此时直接说话即可。

### 2. 播报时如何打断

当设备正在播报时，可以按当前对话方式打断：

- 连续对话模式：直接开口说任意内容，设备会响应并打断当前播报。
- 单轮问答模式：再次说出唤醒词，可以打断当前播报并开始下一轮对话。
- 如果你不方便用语音，任何时候都可以单击主按键打断当前播报。

### 3. 两种对话方式

设备支持两种对话方式：

- 连续对话模式：更适合连续交流。设备播报时，你直接开口说话，也可以打断并继续聊。
- 单轮问答模式：更适合一问一答。设备播报时，再次说出唤醒词，可以打断当前播报并进入下一轮对话。

如果你对模式没有特别要求，保持当前默认设置即可。

### 4. 如何切换对话方式

在设备空闲时，双击主按键，可以在两种对话方式之间切换。

当前选择会自动保存，下次开机后仍然生效。

> 说明：切换模式后，最容易确认当前模式的方法，是在设备播报时试一次打断方式：
>
> - 直接开口就能打断，说明当前是连续对话模式。
> - 需要再次说唤醒词才能打断，说明当前是单轮问答模式。

## 六、按键说明

智伴AI阅读助手只有一个主按键，常用操作如下：

- 启动过程中单击：进入配网模式
- 待机时单击：开始对话
- 对话或播报过程中单击：打断或结束当前这轮对话
- 空闲状态双击：切换对话方式

> 注意：设备已经正常使用后，单击主按键通常是开始对话或打断播报，不是重新配网。

## 七、什么时候需要重新配网

遇到下面这些情况时，可以重新配网：

- 更换了家里的 Wi-Fi
- 小程序一直提示设备未联网
- 设备长时间无法正常连接使用

重新配网方法：

1. 重启设备。
2. 在启动过程中单击主按键。
3. 确认设备发出配网提示音、状态灯开始慢闪。
4. 重新打开微信小程序，按提示完成配网。

## 八、充电与日常使用建议

- 请尽量使用稳定的电源、充电头和线材。
- 如果设备插电后仍然频繁重启、反复断网或无法正常使用，请优先检查供电是否稳定。
- 使用时请不要遮挡麦克风和扬声器位置。
- 建议在相对安静的环境中使用，识别效果更好。
- 长时间不用时，请按产品说明关机或断开外部电源。

## 九、常见问题

### 1. 小程序搜不到设备怎么办

请依次检查：

1. 手机蓝牙是否已开启。
2. 微信小程序是否已获得蓝牙权限。
3. Android 手机是否已开启定位权限。
4. 手机和设备距离是否过远。
5. 设备是否已经进入配网模式，也就是是否听到了配网提示音、看到了状态灯慢闪。

### 2. 配网失败怎么办

请依次检查：

1. 路由器是否开启了 2.4GHz Wi-Fi。
2. Wi-Fi 密码是否输入正确。
3. 路由器信号是否稳定。
4. 手机当前是否连接在可用的 2.4GHz Wi-Fi 上。

如果仍然失败，请重启设备，并在启动过程中单击主按键后重新配网。

### 3. 配网成功后，为什么还不能马上使用

配网成功后，小程序还会继续完成当前用户和设备的绑定。

请以小程序提示为准，等绑定完成后再开始使用。

### 4. 我怎么知道设备已经在听我说话了

通常会有两个明显信号：

- 你会听到一声短提示音。
- 你会看到状态灯进入呼吸变化状态。

这时就可以直接开始说话。

### 5. 播报时能不能直接再说唤醒词来打断

要看你当前使用的是哪一种对话方式：

- 如果是连续对话模式：不需要重复说唤醒词，直接开口说话即可打断。
- 如果是单轮问答模式：再次说出唤醒词，可以打断当前播报。

如果你不方便用语音，仍然可以直接单击主按键打断。

### 6. 唤醒词没反应怎么办

请依次检查：

1. 当前环境是否过于嘈杂。
2. 麦克风孔是否被遮挡。
3. 你与设备的距离是否过远。
4. 设备是否刚开机、正在播报或网络异常。

如果唤醒词暂时没有响应，也可以直接单击主按键开始对话。

### 7. 双击后为什么感觉没变化

双击主按键后，设备会切换对话方式，但不会额外播报当前模式名称。

你可以用下面的方法判断：

- 如果设备播报时，你直接开口就能打断，说明当前是连续对话模式。
- 如果设备播报时，需要再次说唤醒词才能打断，说明当前是单轮问答模式。

## 十、维护与售后

- 本设备不支持远程在线升级。
- 如需升级、检修、重装或恢复，请优先联系设备提供方或售后人员。
- 不建议自行按照通用刷机教程操作，以免影响正常使用。

## 十一、隐私提示

设备在联网对话时，需要将语音和相关请求发送到对应服务端处理。

如你使用的是官方服务，请以官方说明为准；如你使用的是定制服务，请以对应服务提供方说明为准。
